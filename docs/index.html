Method and caveats

  • Data: UNEP Food Waste Index Report 2024 (2022 estimates) and World Bank GDP per capita (PPP, 2022), both via Our World in Data (CC BY 4.0).
  • Region rows ("World", "Africa (UN)") and 5 tiny territories reported as 0 kg were removed. That leaves countries.
  • Many values are modelled: where a country has no study, UNEP fills the gap from similar countries. A household value shared exactly with another country is flagged as "likely estimated".
  • The wealth check uses rank (Spearman) correlation, a bootstrap confidence interval and an OLS regression with continent controls. See the notebook.
  • The hostel mess figures are scenario estimates, not measured waste.
